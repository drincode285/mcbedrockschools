Lesson 1: Ano ang JavaScript? (Simpleng Paliwanag)

JavaScript ay isang programming language — isang paraan ng pagsulat ng mga utos (instructions) na kayang intindihin ng computer. Kung ang JSON ay ang listahan ng sangkap (data), ang JavaScript ang nagluluto: ito ang nagsasabi ng kung ano ang mangyayari at kailan.

📄 JSON = Data

"May espada na may 8 damage at tinatawag na pinoy:kampilan." Hindi ito nag-iisip; naglalarawan lang.

🟨 JavaScript = Logic

"Kapag ginamit ng player ang espada, tapos mag-dash siya at bigyan ng regeneration." Ito ang gumagawa ng aksyon.

Saan ginagamit ang JavaScript?

Sikat ito sa mga website (buttons, animations), sa mga app, at sa mga server. Sa Minecraft Bedrock, may sariling JavaScript engine sa loob mismo ng game. Tinatawag itong Script API (o Creator API) — dito ka makakagawa ng mga bagay na hindi kaya ng JSON lang.

Ang una mong Minecraft script

Sa Minecraft, ang JavaScript ay nakikinig sa mga nangyayari sa world (events) at tumutugon dito. Heto ang pinakasimple — tatlong linya lang:

import { world } from "@minecraft/server";   // 1. kunin ang 'world' mula sa Minecraft

world.afterEvents.playerSpawn.subscribe((event) => {   // 2. kapag nag-spawn ang isang player...
  event.player.sendMessage("§aKumusta, " + event.player.name + "!");   // 3. ...batiin siya sa chat
});
Try it Yourself »

Ang // ay comment — hindi ito binabasa ng computer, para sa atin lang na magbabasa ng code.

Lesson 2: scripts/main.js at ang manifest

Ang JavaScript mo ay isinusulat sa loob ng Behavior Pack, sa folder na scripts. Ang file na tatakbo muna ay sinasabi ng entry sa manifest.

Lesson 3: Paano Mag-Import ng Minecraft Modules sa JavaScript

Sa Bedrock Script API, gumagamit tayo ng ES6 import sa pinakaunang linya ng scripts/main.js. Isinusulat sa loob ng { } ang mga bagay na gusto mong kunin mula sa module:

import { world, system } from "@minecraft/server";
import { ActionFormData } from "@minecraft/server-ui";

Lesson 4: Variables (const / let), Data Types at Color Codes (§)

Ang variable ay parang kahon na may pangalan na pinaglalagyan ng value. Gamitin ang const kapag hindi na mababago, at let kapag babaguhin pa.

const weaponName = "Kampilan";               // string  (text, nasa loob ng "")
let bonusDmg = 20;                           // number  (pwedeng baguhin dahil 'let')
const isRare = true;                         // boolean (true o false)
const skills = ["Dash", "Heal", "Fire"];     // array   (listahan)
const stats = { damage: 8, speed: 1.2 };     // object  (may mga pangalan: key -> value)

bonusDmg = bonusDmg + 5;                     // ngayon 25

// Template literal: gamitin ang `backticks` at ${...} para maglagay ng variable sa text
world.sendMessage(`§6[Skill] §aAng ${weaponName} ay may +${bonusDmg} Damage!`);
Try it Yourself »

Sa Minecraft text, ang § ay nagbabago ng kulay o estilo ng sulat:

§a Green §c Red §e Yellow §6 Gold §b Aqua §l Bold §r Reset

Lesson 5: Functions at Arrow Functions

Ang function ay grupo ng mga utos na may pangalan — isulat nang isang beses, tawagin kahit ilang beses. Tumatanggap ito ng parameters (input) at pwedeng mag-return ng sagot.

// Karaniwang function
function showHud(player, text) {
  player.onScreenDisplay.setActionBar(text);
}

// Function na nagre-return ng sagot
function computeDamage(base, bonus) {
  return base + bonus;
}
const total = computeDamage(8, 20);   // 28

// Arrow function (mas maikli) - ito ang makikita mo sa mga event
const double = (n) => n * 2;
double(4);                            // 8
Try it Yourself »

Ang (event) => { ... } na ginagamit sa .subscribe() ay arrow function din — tatakbo ito tuwing may nangyaring event.

Lesson 6: if / else at for...of Loops

Ang if ay nagpapasya: tatakbo lang ang code kapag true ang kondisyon. Ang for...of ay inuulit ang code para sa bawat item sa listahan (hal. bawat player).

for (const player of world.getAllPlayers()) {   // para sa BAWAT player...
  if (player.isSneaking) {                       // ...kung nakayuko siya
    player.sendMessage("§eNakayuko ka!");
  } else if (player.location.y < 0) {            // ...o kung nasa ilalim ng y = 0
    player.sendMessage("§cMalalim na masyado!");
  } else {
    player.sendMessage("§aNakatayo ka.");
  }
}

Lesson 7: Paano Gumagana ang .subscribe() Events

Gumamit ng arrow function (event) => { ... } para patakbuhin ang iyong code kapag may nangyari sa mundo. Ang event ay may impormasyon tungkol sa nangyari:

world.afterEvents.entityHitEntity.subscribe((event) => {
  const attacker = event.damagingEntity;   // sino ang pumalo
  const target = event.hitEntity;          // sino ang pinalo
  target.setOnFire(5, true);               // sunugin ng 5 segundo
});
Try it Yourself »

afterEvents vs beforeEvents

afterEvents — nangyari na. Dito mo malayang magagamit ang halos lahat ng function (sendMessage, addEffect, spawnEntity…).
beforeEvents — mangyayari pa lang, kaya pwede mo itong i-cancel. Pero read-only ang mode: para magpalit ng bagay sa world, ibalot sa system.run().
import { world, system } from "@minecraft/server";

world.beforeEvents.playerBreakBlock.subscribe((event) => {
  if (event.block.typeId === "minecraft:diamond_ore") {
    event.cancel = true;                       // huwag hayaang masira
    system.run(() => {                         // tumakbo sa susunod na tick
      event.player.sendMessage("§cBawal sirain ang diamond ore dito!");
    });
  }
});
Try it Yourself »

Lesson 8: system.runInterval() at runTimeout()

Tandaan: 20 ticks = 1 segundo sa Minecraft Bedrock! Ang runInterval ay paulit-ulit, ang runTimeout ay isang beses lang pagkatapos ng delay.

// Paulit-ulit: bawat 20 ticks (1 segundo)
system.runInterval(() => {
  for (const player of world.getAllPlayers()) {
    player.onScreenDisplay.setActionBar("§bMana: 100/100");
  }
}, 20);

// Isang beses: pagkatapos ng 100 ticks (5 segundo)
system.runTimeout(() => {
  world.sendMessage("§e5 segundo na ang lumipas!");
}, 100);
Try it Yourself »
1 tick = 0.05s 20 ticks = 1s 100 ticks = 5s 1200 ticks = 1 minuto

Lesson 9: Pagsamahin Lahat — Custom Item Skill na may Cooldown

Gamitin natin ang lahat ng natutunan: import, variables, if, event at ticks. Kapag ginamit ng player ang pinoy:bayanihan_blade, magda-dash siya — pero may 5 segundong cooldown.

import { world, system } from "@minecraft/server";

const cooldowns = new Map();                 // player.id -> tick kung kailan pwede ulit

world.afterEvents.itemUse.subscribe((event) => {
  const player = event.source;
  if (event.itemStack.typeId !== "pinoy:bayanihan_blade") return;   // ibang item? huwag pansinin

  const now = system.currentTick;
  if (now < (cooldowns.get(player.id) ?? 0)) {
    player.sendMessage("§cNagko-cooldown pa ang skill!");
    return;
  }
  cooldowns.set(player.id, now + 100);       // 100 ticks = 5 segundo

  const view = player.getViewDirection();
  player.applyKnockback({ x: view.x * 3, z: view.z * 3 }, 0.5);   // dash pasulong
  player.onScreenDisplay.setActionBar("§b⚡ Wind Dash!");
});
Try it Yourself »
💡 Sa @minecraft/server 2.x, ang applyKnockback ay tumatanggap ng { x, z } (kasama na ang lakas) at hiwalay na vertical strength — hindi na apat na number.
