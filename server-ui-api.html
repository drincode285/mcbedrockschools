Lesson 1: ActionFormData (Menu na may Buttons)

Ginagamit para sa RPG Class Picker, Server Warps, at NPC Shops. Subukang i-click ang buttons sa Live UI Simulator sa kanan!

📦 Ang mga halimbawa sa page na ito ay para sa @minecraft/server-ui 2.2.0 (Minecraft 1.26.50) — tingnan ang version matrix. Kailangan itong nakalista sa dependencies ng manifest mo.
import { ActionFormData } from "@minecraft/server-ui";

const form = new ActionFormData()
  .title("Pumili ng Iyong RPG Class")
  .body("Piliin ang starter kit na gusto mong gamitin:")
  .button("🗡️ Mandirigma (+15 ATK)")
  .button("🏹 Mangangaso (Speed II)")
  .button("✨ Babaylan (Regen Aura)");

form.show(player).then((res) => {
  if (res.canceled) return;
  player.sendMessage("Selected button index: " + res.selection);
});

Lesson 2: ModalFormData (Textfields, Sliders, Dropdowns, Toggles)

import { ModalFormData } from "@minecraft/server-ui";

const modal = new ModalFormData()
  .title("⚙️ Add-On Skill Settings")
  .textField("Custom Guild Tag:", "[PH]", { defaultValue: "[PH]" })
  .slider("Dash Power Level", 1, 10, { valueStep: 1, defaultValue: 5 })
  .dropdown("Element", ["Apoy", "Kidlat", "Hangin"], { defaultValueIndex: 0 })
  .toggle("Show ActionBar HUD", { defaultValue: true });

modal.show(player).then((res) => {
  if (!res.canceled) console.warn(JSON.stringify(res.formValues));
});
