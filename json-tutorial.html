Lesson 1: JSON Syntax Rules para sa Minecraft Add-Ons

Lahat ng data files sa Minecraft Bedrock (items, blocks, entities, recipes) ay nakasulat sa JSON. Tandaan ang 3 gintong patakaran:

  • Laging gumamit ng double quotes ("key")—bawal ang single quotes.
  • Bawat property ay pinaghihiwalay ng kuwit (,), maliban sa pinakahuling property sa loob ng block.
  • Laging magsisimula ang file sa "format_version".

Lesson 2: Custom Weapon / Item JSON (BP/items/)

Halimbawa ng custom sword na may +15 attack damage at custom icon shortname:

{
  "format_version": "1.21.10",
  "minecraft:item": {
    "description": {
      "identifier": "pinoy:kampilan_sword",
      "menu_category": { "category": "equipment", "group": "itemGroup.name.sword" }
    },
    "components": {
      "minecraft:max_stack_size": 1,
      "minecraft:hand_equipped": true,
      "minecraft:durability": { "max_durability": 1200 },
      "minecraft:damage": { "value": 15 },
      "minecraft:icon": "kampilan_sword"
    }
  }
}

Lesson 3: Custom Block JSON (BP/blocks/)

Halimbawa ng custom glowing ore block:

{
  "format_version": "1.21.10",
  "minecraft:block": {
    "description": {
      "identifier": "pinoy:pearl_ore",
      "menu_category": { "category": "nature" }
    },
    "components": {
      "minecraft:destructible_by_mining": { "seconds_to_destroy": 3.0 },
      "minecraft:light_emission": 12
    }
  }
}

Lesson 4: Shaped Crafting Recipe (BP/recipes/)

{
  "format_version": "1.20.10",
  "minecraft:recipe_shaped": {
    "description": { "identifier": "pinoy:kampilan_recipe" },
    "tags": ["crafting_table"],
    "pattern": [" G ", " G ", " R "],
    "key": {
      "G": { "item": "minecraft:gold_block" },
      "R": { "item": "minecraft:blaze_rod" }
    },
    "unlock": [{ "item": "minecraft:gold_block" }],
    "result": { "item": "pinoy:kampilan_sword", "count": 1 }
  }
}
