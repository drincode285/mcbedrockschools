# MCBedrockSchools — Multi-Page W3Schools-Style Minecraft Bedrock Modding Website

## Project Folder Structure
```text
mcbedrock-schools/
├── index.html                  # Home & Course Tracks
├── beginner-guide.html         # Mobile (ZArchiver, Code Studio, ibisPaint X vs High-End) & PC Setup
├── folder-structures.html      # Interactive BP & RP Folder Explorer
├── json-tutorial.html          # Step-by-step JSON Course & Live Syntax Validator
├── javascript-course.html      # Step-by-step JavaScript for MCBE Modders
├── server-api.html             # @minecraft/server Built-in Classes & Functions Reference
├── server-ui-api.html          # @minecraft/server-ui Reference & Live In-Game UI Simulator
├── versions.html               # Version Matrix & Live manifest.json Generator
├── tryit-practice.html         # W3Schools "Try It Yourself" Simulator & 6 Exercises
├── css/
│   └── style.css               # Modular Stylesheet
├── scripts/
│   ├── common.js               # Shared Navigation, Step Pagination, UUID v4, XP & Search
│   ├── folder-explorer.js      # Interactive BP/RP File Tree Inspector
│   ├── json-validator.js       # Live JSON Syntax Validator
│   ├── server-api-docs.js      # Filterable @minecraft/server API Reference
│   ├── server-ui-simulator.js  # Interactive @minecraft/server-ui Form Preview
│   ├── manifest-builder.js     # Live manifest.json Generator
│   └── tryit-lab.js            # Code Playground & Fill-in-the-Blank Exercises
└── images/
    ├── hero-studio.jpg         # 3D Voxel Coding Studio Banner
    ├── logo-mcbe.svg           # MCBedrockSchools Logo
    ├── bp-rp-architecture.svg  # Resource Pack vs Behavior Pack Diagram
    └── mobile-workflow.svg     # Low-End vs High-End Mobile Modding Tools Diagram
```
